# 콘텐츠 임포트 폴더

현행 학부 홈페이지에서 저장한 HTML을 여기에 넣으세요.

## 넣는 법
- **`.html` 파일만** 이 폴더에 복사하세요. (같이 생기는 `*_files/` 폴더 = 이미지/CSS/JS는 **안 넣어도 됩니다.**)
- 파일명을 알아보기 쉽게 바꿔주면 좋습니다. 예:
  - `연혁.html`, `교수진.html`, `교육목표.html`, `졸업요건.html`, `BK21.html` ...
- 이미지도 꼭 살리고 싶은 페이지가 있으면, 그 페이지의 `*_files/` 폴더 안 이미지들만
  `public/img/imported/` 로 복사해 두면 나중에 연결할 수 있습니다. (선택 사항)

## 다음 단계
파일을 넣은 뒤 알려주시면, `scripts/extract_import.py` 를 돌려서
각 HTML의 **본문만** 추출해 `_import/out/*.md` 로 뽑아냅니다.
(원본 HTML을 통째로 읽지 않으므로 토큰을 아낍니다.)
그 결과를 확인해서 사이트 데이터(`content/*.json`)와 페이지에 반영합니다.
